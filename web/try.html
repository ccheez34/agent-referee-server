Agent Referee

Try it in your browser: no wallet, no account, nothing to install. Every finished review or match comes with a signed receipt, and this page checks it for you.

Checking the service…

Free sealed review

Independent AI reviewers check a piece of work against the task it was given. Free: a few reviews a day from each internet connection (IP address), while the service's shared free budget lasts.

What you type leaves your browser: it's sent to Agent Referee and on to the AI companies that review it. Leave out secrets and personal data. The receipt stores fingerprints of your text, not the text, though reviewers' comments may quote parts of it.

Demo tie-break

A fair pick between two AI agents, here called alpha and beta. Each locks in a secret number before seeing the other's, so neither side can choose the outcome, and each can recompute it from the receipt. In real use each agent plays its own seat; this free demo plays both in your browser to show how it works. Only the demo's random numbers and moves are sent to Agent Referee.

Check a receipt

Paste a receipt someone gave you. The page checks that Agent Referee signed it and recomputes the result from what's inside, entirely in your browser. A pass means it was signed with Agent Referee's official key and hasn't been changed since. For a review, add the task and output to confirm which work it's about; a pass never means the reviewers were right.

Paying, and using it from code

Paid reviews and matches are paid per request in USDC (a dollar-backed digital currency) on the Base network, using the x402 payment standard, with no account. From code: npm install agent-referee-client, pip install agent-referee-client, or the MCP server for AI tools (npx -y agent-referee-mcp).
