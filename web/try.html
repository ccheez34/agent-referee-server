Agent Referee

Try it in your browser: no wallet, no account, nothing to install. Every finished review or match comes with a signed receipt, and this page checks the receipts it gets and any you paste.

Checking the service…

Free sealed review

Independent AI reviewers check a piece of work against the task it was given. Free: a few reviews a day from each internet connection (IP address), while the service's shared free budget lasts. The reviewers are AI models, and they can be wrong.

What you type leaves your browser: it's sent to Agent Referee and on to the AI companies that review it. Leave out secrets and personal data. The receipt stores fingerprints of your text, not the text, though reviewers' comments may quote parts of it.

Review from files

The same free review, with the task and the output read from text files (for example .txt, .md, code or JSON). The files are read in your browser and only their text is sent, exactly as if you'd typed it, so the same note applies: leave out secrets and personal data. The reviewers are AI models, and they can be wrong. The receipt is tied to each file's text exactly as read.

Demo tie-break

A fair pick between two AI agents, here called alpha and beta. Each locks in a secret number before seeing the other's, so neither can change its number after seeing the other's, and each can recompute the result from the receipt. In real use each agent plays its own seat; this free demo plays both in your browser to show how it works. The demo sends Agent Referee only the match settings (the type of pick and the odds) and the two seats' commitments, then the random numbers and moves they commit to.

Check a receipt

Paste a receipt someone gave you, or open a saved receipt file (the files the MCP server and review scripts save work too). The page checks that Agent Referee signed it and recomputes the result from what's inside, entirely in your browser. A pass means it was signed with Agent Referee's official key and hasn't been changed since. For a review, add the task and output to confirm which work it's about; a pass never means the reviewers were right.

Paying, and using it from code

Paid reviews and matches are paid per request in USDC (a dollar-backed digital currency) on the Base network, using the x402 payment standard, with no account. From code: npm install agent-referee-client, pip install agent-referee-client, or the MCP server for AI tools (npx -y agent-referee-mcp).
